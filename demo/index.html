🔐 Milestone Vault

Milestone-based escrow payments on Tari Ootle — lock the full payment up front, release it piece by piece as work is approved.

⚠ SIMULATED DEMO. This page is a browser-only simulation of the template's behaviour. The Milestone Vault template is not published to mainnet, this demo connects to no wallet and no chain, and no real funds move. It exists so reviewers can walk the exact flow the Rust template enforces on-chain (the template itself is covered by in-process engine tests — see the repository README).

1 · Set up the job

The client defines the milestones and the timeout policy, then locks the full amount. Both are fixed at creation — on-chain, the component has no owner, so the rules can never be changed afterwards.

Timeout policy (locked at creation)

Why this choice matters: refund protects the client against non-delivery; auto-release protects the freelancer against a client who goes silent after the work is done. A milestone that was never submitted is refunded under both policies.
